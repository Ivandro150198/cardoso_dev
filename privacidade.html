Privacidade

O que acontece com os dados do contato.

Esta página descreve o formulário do site de Ivandro Cardoso. Ao marcar a caixa de consentimento, você aceita o que está escrito aqui.

Quem recebe

Ivandro Cardoso, no email ivandrotc11@gmail.com.

Dados pedidos

Nome, email, assunto e mensagem. O campo oculto “website” serve só para filtrar envios automáticos e deve ficar vazio. Não é usado como dado pessoal.

Para quê

Responder ao pedido: projeto, colaboração, dúvida técnica, currículo ou feedback.

Como o envio funciona

Num servidor com PHP, o formulário tenta enviar esses dados por email. Em alojamento só de ficheiros, como GitHub Pages ou Vercel, esse envio não existe. Nesse caso o site abre a mesma mensagem no programa de email do seu dispositivo. Não há conta de utilizador nem base de dados neste site.

O que não é feito

Estes dados não são vendidos. O site não usa cookies de publicidade. A escolha de tema claro ou escuro fica apenas no seu navegador.

Conservação

A mensagem fica na caixa de email até ser apagada. O site não guarda outra cópia.

Correção ou apagamento

Para corrigir ou apagar uma mensagem já enviada, escreva para ivandrotc11@gmail.com.
